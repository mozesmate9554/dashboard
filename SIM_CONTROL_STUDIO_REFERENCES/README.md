# SIM_CONTROL_STUDIO_REFERENCES

Autónként rendszerezett referencia-könyvtár a 0.4.0 fejlesztéshez.

**Fontos:** ebben a könyvtárban **nincs** a játékból kinyert grafika. Csak a játék saját fájllistájából olvasott eszköznevek és internetes referencialinkek szerepelnek. A `Cockpit_Screenshots` mappákba a felhasználó saját játékbeli képernyőképei kerülnek, ezek alapján pontosítjuk a műszerfalakat és a kezelőpaneleket. A kiadott alkalmazás grafikája saját rajz.

Részletek: `documentation/GAME_ASSET_REFERENCE_REPORT.md`, `documentation/VEHICLE_REFERENCE_REPORT.md`.
